## Shipping Options (per FAQ 2605)
| Method | Fee | Replacement ships | Defective return deadline |
|--------|-----|-------------------|--------------------------|
| Standard | $0 | After TP-Link receives defective unit | Per instructions in box |
| Advanced Basic | $14.99 | Now (ground) | 25 days from RMA request |
| Advanced 2-Day | $24.99 | Now (2-day delivery) | 25 days from RMA request |
| Advanced Next-Day | $49.99 | Now (next-day) | 25 days from RMA request |

Advanced RMA includes prepaid return label in replacement box. Non-return triggers full device cost charge + PayPal authorization hold becomes a real charge.

## Portal Flow Post-Authorization
1. Navigate to portal link, log in with TP-Link account (not Gmail — separate credentials)
2. Case shows as authorized if it appears at "Select Shipping Method" stage
3. Confirm physical shipping address (no PO Box) — add new address if needed under Account Info > Edit > Save Address
4. Click "Shipping Method" button → select Standard vs Advanced option
5. Select/review shipping address
6. Review case summary (fees, subtotal, tax, shipping)
7. Complete payment via PayPal (guest checkout available)
8. Note: 3-5 business days processing time after payment
