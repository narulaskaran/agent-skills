# Knowledge base workflow

This folder holds durable notes about the owner's life: projects, people, health, home, travel, finance.

## Finding things
1. Start at `INDEX.md`, then open the category's `index.md`. Each line there is `- [Title](file.md) — one-line summary`.
2. Open only the note you need. Use grep across the folder when the index does not point to it.
3. The note is the authority. Read it before answering from memory or proposing changes.

## Writing things
- One topic per note, in the category it belongs to. Check for an existing note before creating one; never make a second note for the same topic under a different spelling.
- Start each note with a `summary:` line in front matter, then `# Title`, then `## Current decisions`, then history.
- When the owner makes a lasting decision or shares a durable fact, write it to the note while it is fresh, with the date.
- Keep earlier decisions; mark them superseded instead of deleting them.
- After adding or renaming a note, update that category's `index.md`.
- Things the owner said are decisions. Things you suggested are proposals until the owner agrees.
